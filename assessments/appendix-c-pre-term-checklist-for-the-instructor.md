# Appendix C: Pre-Term Checklist for the Instructor

[⬅ Assessments index](README.md)

1. Install and test Python 3.12+, Node LTS, Git, VS Code, Docker and WSL on a sample lab PC; confirm virtualisation is enabled.
1. Check outbound access to PyPI, npm, GitHub, Docker Hub and your chosen API provider from the lab network.
1. Pick the cloud emulator (Moto recommended), install it and run the Week 10 script against it.
1. Create or verify a free-tier API key, or deploy the mock API for everyone.
1. Create a Discord or Slack test webhook for Week 11.
1. Pre-pull `python:3.12-slim` and share it by `docker save` if the lab bandwidth is limited.
1. Confirm the textbook chapter numbers for your edition and update the reading column.
1. Look up the current pinned version of `aquasecurity/trivy-action` and the current majors of the official GitHub actions.
1. Create a GitHub organisation or Classroom, branch-protection template and repository template.
1. Prepare a broken-script bank (one logical bug each) for the class task, and sample logs or CSVs with malformed lines.
1. Decide and announce the AI-use rule and viva procedure.
